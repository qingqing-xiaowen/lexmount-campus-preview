学生 Pro 与账号资源

活动专属入口新注册、符合条件的学生，可获得约两个月 Lexmount 云平台 Pro。这是学生福利；学生、非学生和混合团队均可竞争全部奖项。

  • 以申请学生权益时是否在读认定学生资格，不影响参赛与现金评奖。优先复用平台已有认证；确需证明时，学生证或在读证明选一，可遮挡无关信息。
  • 混合团队不代表全队自动获得学生福利；同一个人不会因多件作品重复领取。不要求全体参赛者上传学籍材料。
  • 已有账号可以使用当前可用资源。老账号、已付费账号如何适用活动权益，需要产品说明，不承诺自动加赠。

从账号到一次可核验的实践

  1. 准备可用账号和资源。符合学生福利条件的新用户等待活动专属入口；已有账号先确认自己的可用额度与工具费用。
  2. 按官方指南配置项目和 API Key。网页 Playground 也需要 API Key。密钥只用于可信产品环境，不提交给报名表、投稿表或案例文档。
  3. 选择一种已有路径。可使用 Cloud Browser / Web Fetch Playground，或按指南接入 Agent、脚本等工具；不同能力和工具组合按当前文档核对。
  4. 完成一个核心任务并保存证据。留下云平台参与的环节、主要运行过程、结果和限制。遇到错误可先排查和调整；任务核心未完成的探索不作为实践激励获奖案例。
  5. 简要投稿，保存真实回执。在表单填写摘要并附材料链接，记录 1—5 名实际贡献者。收到接收端确认后才算收件；需要纠错时使用回执给出的途径。

核验、补证与结果通知

暂定 2026 年 10 月 12 日开始，10 月 31 日 23:59 截止报名与投稿（北京时间），共 20 天、约三周。截稿后开展核验与评选，结果在活动页公布；具体评选和公布日期另行通知。必要通知发送至报名或投稿中留下的联系邮箱，不要求必须入群。当前预览不发送通知。

需要补证时，团队会说明核验内容、具体截止日期和时间、提交渠道。补证时限随正式核验通知说明；只补证明投稿截止时已有成果的材料，不延长开发。现有证据充分时，不会因为缺少一份非必要附件就机械取消资格。

已提交记录怎样纠错

先保存真实回执编号。如果回执提供已提交记录的修改链接，可按链接操作；未提供时，通过 support@lexmount.cn 联系团队，说明回执编号、当前联系邮箱和需要纠正的内容。团队核对后处理。

页面内“返回修改”只修改当前填写内容，不会更新接收端记录。截止后只接受必要信息纠错或既有成果补证，不允许换作品、换作者套奖。

当前报名与投稿仍为预览，没有生成真实记录；正式收件与修改入口上线后，以回执说明操作。咨询无需入群。

私有材料怎样让评审看见

  • 可提供脱敏后的只读公开链接，或在活动指定方式公布后，为评审开通所需权限。
  • 评审账号/接收方式：尚待配置，不要自行猜测邮箱或向未经确认的账号授权。
  • 链接应覆盖评审及必要补证时段；具体日期公布后核对有效期。限制登录、需要审批或有提取码时，在投稿表“访问说明”中单独注明。
  • 提取码不要仅写在打不开的材料内。可以提供材料的提取码，但不要提供账号登录密码、API Key 或其他凭据。
  • 内部核验材料与可公开摘要/演示分开存放和标记。无需提交所有形式的证据，能充分说明云平台使用和结果即可。

必要信息、内部评审与公开展示

报名和投稿信息用于联系、活动组织、作品核验、必要纠错及评奖。初次报名不收银行账户等发奖资料，不要求全体参赛者提交学籍材料。涉及学生 Pro 时按最少必要原则认证。

获奖作品须能提供可公开的脱敏案例摘要与必要演示素材，供官网择优展示；无法提供任何可公开案例内容的作品，不满足本次获奖案例要求。实际发布前确认具体内容与署名，不承诺每件作品一定上线官网。

作品权利仍归作者，不要求全部源码开源。学籍证明、账号凭据、客户原始数据及内部核验材料不直接公开。请在提交前脱敏，确保对第三方内容拥有适当使用权限。

活动数据保存期限、实际接收系统、授权访问范围及更正/删除联系入口需在正式开放前随活动隐私说明补齐；当前预览尚未接入正式收件。平台已有政策可见Lexmount 隐私政策。
